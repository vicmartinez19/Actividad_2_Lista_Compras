# Actividad 2: Lista de Compras Interactiva (Manejo de Estado con useState)

## 📌 Descripción del Proyecto
Esta aplicación permite gestionar una lista de compras interactiva utilizando el hook fundamental `useState` de React. Permite:
- Agregar productos con nombre, categoría y cantidad.
- Eliminar productos utilizando filtrado inmutable (`.filter()`).
- Alternar el estado de comprado mediante mapeo inmutable (`.map()`).
- Filtrar la lista entre todos, pendientes o comprados.
- Persistencia automática de los productos en `localStorage`.
- Prevención de productos duplicados y validación de formulario.
- Totalmente compatible con **GitHub Pages** mediante `base: './'`.
